📋 1. Project Overview

App Name

Prasar PR — Strategic Public Relations

App Type

Single-page application (SPA), corporate website

Target Audience

Healthcare, educational, and civic institutions

Backend?

No. Fully frontend-only. No API calls, no database.

ℹ️
Important: There is no routing library. All sections live on a single page. Navigation works by smooth-scrolling to anchor IDs using scrollIntoView(). There are no URLs like /about or /services.

The app communicates Prasar's brand: institutional credibility, narrative precision, and trust-based relationships. The design is luxury minimalist — navy, ochre, and pearl tones with serif headings.

🎭 7. Spacing & Animation

Section Spacing Pattern

All page sections use consistent vertical padding:

<section className="py-20 lg:py-28 px-6">
  <div className="max-w-content mx-auto">
    {/* content */}
  </div>
</section>

max-w-content = 1200px (defined in Tailwind config)

Scroll-Triggered Fade-In (CSS Pattern)

Most sections use this IntersectionObserver + CSS class pattern:

/* index.css */
.fade-in-up {
  opacity: 0;
  transform: translateY(24px);
  transition: opacity 0.6s ease, transform 0.6s ease;
}
.fade-in-up.visible {
  opacity: 1;
  transform: translateY(0);
}
// In component JSX:
<div className="fade-in-up" style={{ transitionDelay: '160ms' }}>
  Content
</div>

// In useEffect:
const observer = new IntersectionObserver(
  (entries) => entries.forEach((e) => {
    if (e.isIntersecting) e.target.classList.add('visible')
  }),
  { threshold: 0.1 }
)
ref.current?.querySelectorAll('.fade-in-up').forEach((el) => observer.observe(el))

Aurora Background Animation

The aurora CSS animation is defined in index.css as @keyframes aurora and applied via the aurora-animate class. It animates background-position to create a flowing gradient effect.

Framer Motion (3D Scroll)

Used only in the Hero section via ContainerScrollAnimation. It maps scroll progress to rotateX, scale, and translateY values using useScroll + useTransform.

Reusable

Location: src/components/ui/container-scroll-animation.jsx

A Framer Motion-powered component that creates a 3D rotating card effect as the user scrolls. Used in Hero.jsx.

Props

PropTypeDescription
titleComponentReactNodeText/element to display above the 3D card
childrenReactNodeContent inside the 3D card (typically an image)

Usage

<ContainerScroll
  titleComponent={<h2>Your title here</h2>}
>
  <img src="/your-image.jpg" alt="..." />
</ContainerScroll>

How It Works

  • Uses Framer Motion useScroll to track viewport scroll position
  • Maps scroll progress to rotateX (0° → 20°), scale (1.05 → 1), and translateY
  • Detects mobile (window.innerWidth < 768) to adjust scale factors

🔄 12. State Management

ℹ️
No global state library. This app uses only React's built-in hooks. There is no Redux, Zustand, Context API, or Recoil.

Each component is self-contained and manages its own local state. Here's a summary of state used across the app:

ComponentState VariablesPurpose
Navbar scrolled, menuOpen, active Scroll detection, mobile menu, active section highlight
Hero loaded Whether the hero background image has finished loading
Contact form, errors, submitted Form field values, validation errors, submission state
All sections ref (useRef) DOM reference for IntersectionObserver to watch .fade-in-up elements

Common Hook Patterns

// Scroll listener (Navbar)
useEffect(() => {
  const onScroll = () => setScrolled(window.scrollY > 80)
  window.addEventListener('scroll', onScroll, { passive: true })
  return () => window.removeEventListener('scroll', onScroll)
}, [])

// IntersectionObserver (all animated sections)
const ref = useRef(null)
useEffect(() => {
  const observer = new IntersectionObserver(
    (entries) => entries.forEach(e => {
      if (e.isIntersecting) e.target.classList.add('visible')
    }),
    { threshold: 0.1 }
  )
  ref.current?.querySelectorAll('.fade-in-up').forEach(el => observer.observe(el))
  return () => observer.disconnect()
}, [])

📝 14. Forms & Validation

The contact form in Contact.jsx is the only form in the app. Validation is done client-side with a custom validate() function.

const validate = () => {
  const errs = {}
  if (!form.name.trim())    errs.name    = 'Please enter your full name'
  if (!form.org.trim())     errs.org     = 'Please enter your organisation'
  if (!form.role.trim())    errs.role    = 'Please enter your role'
  if (!form.email.trim())   errs.email   = 'Please enter your email'
  else if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(form.email))
                            errs.email   = 'Please enter a valid email address'
  if (!form.enquiry)        errs.enquiry = 'Please select the nature of your enquiry'
  if (!form.message.trim()) errs.message = 'Please provide a brief'
  return errs
}

Enquiry Dropdown Options

  • Reputation Management
  • Crisis Communications
  • Institutional Narrative
  • Media Relations
  • Community Engagement
  • General Enquiry

To Wire Up the Form
